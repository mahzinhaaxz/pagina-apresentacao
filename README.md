# pagina-apresentacao

Lisboa, uma apresentação 
Este repositório foi criado para a UC00617 (Git e GitHub).

 Descrição
 O ficheiro "index.txt" apresenta a cidade de Lisboa. Escolhi este tema porque Lisboa representa uma grande parte da minha vida. O ficheiro tem um menu e um rodapé, feitos em branches separadas.

  Ficheiros do repositório
  - index.txt: ficheiro principal
  - README.md: explicação do projeto
  - .gitignore: ficheiros que o Git não guarda
  - LICENSE: licença MIT

Como usar
1. Clonar o repositório: "git clone https://github.com/mahzinhaaxz/pagina-apresentacao.git"
2. Abrir o "index.txt" num editor de texto.
